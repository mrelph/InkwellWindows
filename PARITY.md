# Inkwell for Windows — Parity with InkwellMac

Reference: `mrelph/InkwellMac` @ `78320c1` (v0.1.0, Swift/SwiftUI). Target: this repo @ `2b34c42` (v0.1.4, Electron/React).
Goal: Windows offers the same functions, design, and capabilities as Mac, expressed in Windows idioms (Ctrl not ⌘, Explorer not Finder, Recycle Bin not Trash, F11 for full screen, jump lists for recents).

### Implementation notes (deliberate Mac divergences)

- **Get Latest from Ephy cannot be undone.** Mac registers the text and the
  link version in one undo group. Windows' textarea undo cannot carry the link
  version, so after Get Latest replaces a note the editor's undo history is
  cleared (`EditorHandle.resetHistory`) and the prompt says "This cannot be
  undone" — otherwise Undo could restore old text while the stored version is
  already the new one, and a later Save would publish stale text.
- **Updates come from GitHub Releases of `mrelph/InkwellWindows`**, verified by
  SHA-256 (plus Authenticode when the running app is signed) and installed by
  the NSIS installer, which relaunches. The portable build and a dev checkout
  open the release page instead. The manual check answers in a native message
  box (Install / Later / Skip This Version), like Mac's alert.
- **No Window menu.** Windows' native frame and taskbar own window management;
  the menu is File / Edit / View / Integrations / Help, hidden until Alt.
- **Jump list instead of the Dock menu:** Recent files plus a "New note" task
  (`--new-note`).
- **h4–h6 stay uppercase**, which matches Mac's actual source and screenshots
  (the original audit row below was wrong).
- **Reader find** paints matches with the CSS Custom Highlight API rather than
  `webContents.findInPage`; a match split across inline elements is not found.
- **The agent panel can only be opened while the agent is enabled**, and
  turning the agent off closes it (Mac).
- **Note images follow the Mac's `Paths.resolveImage`**: any image on a local
  drive loads — relative with `../`, absolute, `~`. Windows adds one rule the
  Mac does not need: a **network** image (UNC, `\\?\`/`\\.\`, a drive letter
  mapped to a share) loads only inside a library folder or the folder of a
  note main opened on that share, and anything else is refused before any fs
  call (touching `\\server\share` sends the user's NTLM hash). A compromised
  renderer can read local images but has no channel out (CSP `img-src 'self'
  inkwell-asset:`, `connect-src 'self'`).
- **Main is the path authority** (Mac has no renderer trust boundary): it
  writes only Markdown documents it handed out (dialog, argv, library walk,
  Save dialog, its own rename/duplicate — any other Markdown path gets a Save
  dialog seeded with it, anything else is refused), reads only those plus
  library contents, startup Recent and reader-link targets, takes library
  folders only from Add Folder or the library.json it loaded at startup
  (never a drive root, the home folder or a folder holding it — Mac's sandbox
  refuses home and `/` for the agent), and every IPC sender must be the app's
  own page. The agent and Ephy can be enabled only from the Integrations menu.
- **Footnotes** render (Mac lacks them): kept.

## 10. Keyboard map (Mac → Windows)

AltGr: Windows reports AltGr as Ctrl+Alt, and AltGr is how German, French and
Spanish layouts type `\`, `@`, `{`, so a Ctrl shortcut never fires while Alt
is down unless it asks for Alt, and the Ctrl+Alt ones (Copy Path, Agent panel)
ignore an AltGr press (`getModifierState('AltGraph')`). Tested in
`src/app/shortcuts.test.ts`.

### Rules for every workstream

1. Edit only files you own. Frozen files (App.tsx, commands.ts, shortcuts.ts,
   activeDocument.tsx, integrations.tsx, bootstrap.tsx, `src/lib/*`, the frozen
   components, contract.ts, preload.ts, vite-env.d.ts, main.ts, settings.ts)
   need a reported contract change.
2. New CSS goes in a co-located `*.css` imported by your module, never
   `styles.css` (E only). No color literals in any CSS; tokens only
   (THEMING.md). Never set `grid-column`, `grid-template-columns` or a region's
   `display` outside `styles.css`.
3. Anything mounted beside the grid (FindController, EphyPicker, dialogs) is
   `position: fixed`; it must never take a grid cell.
4. Main-process modules register their IPC once (module-level `registered`
   flag) and rebind to the newest window on later calls.
5. Never put personal data or note content in URLs, logs, or files the contract
   does not name. Ephy content goes over stdin/stdout only.
6. The renderer never hands `shell.openExternal` a URL; main builds it.
7. Gates for every workstream: `corepack pnpm typecheck`, `corepack pnpm build`,
   `corepack pnpm test`, and the CDP boot check in an isolated
   `--user-data-dir` (CLAUDE.md, "Layout invariants").
